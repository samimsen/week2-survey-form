# Survey Form - CSS Practice

## Proje Hakkında
Bu proje, **CSS pratiği yapmak ve modern form tasarımı öğrenmek** amacıyla hazırlanmış bir HTML form uygulamasıdır. Kullanıcı bilgilerini toplamak için çeşitli form elemanları içerir ve Google Material Icons kullanılarak görsel olarak desteklenmiştir.
